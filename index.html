Project Overview

Built as an internal-style procurement application concept, then converted here into a sanitized public portfolio demo. All values and names on this page are fictional.

The challenge

  • Procurement information is spread across operational spreadsheets.
  • Invoice and payment status need quick operational visibility.
  • Buyers need searchable purchasing history when evaluating repeat purchases.

The solution

  • A single control center with dashboard-style monitoring.
  • Invoice control and payment-status views with operational filters.
  • Purchase History search for PO, item, vendor, and site.

Project 02 · Procurement Automation

AUTO SORTIR

From Excel PO Export to Monitoring — automatically. Designed to reduce repetitive manual sorting, data transformation, and formatting in procurement operations.

INPUT

Excel PO Export

  • Import procurement PO export from Excel.
  • Read PO, PR, vendor, buyer, quantity, approval date and ETA data.
  • Drag & drop supported in the desktop application.
OUTPUT

Monitoring Format

  • Standardized procurement monitoring structure.
  • Automatic date formatting.
  • Automatic ETA calculation.
  • Buyer name normalization.
  • Ready-to-use Excel output.
